# 聖經經文 · Bible text

本資料夾收錄五卷經文：瑪竇福音、馬爾谷福音、路加福音、若望福音、宗徒大事錄
（`matthew.md`、`mark.md`、`luke.md`、`john.md`、`acts.md`），
採用**思高聖經譯本**（思高聖經學會 Studium Biblicum Franciscanum 譯）的繁體中文經文。
